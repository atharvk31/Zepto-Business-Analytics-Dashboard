# Zepto-Business-Analytics-Dashboard | Power-BI
Interactive Power BI dashboard analyzing Zepto sales performance, customer behavior, product trends, KPIs, and regional insights using DAX and data modeling.

---

# 📌 Project Overview

This project presents an interactive **Power BI dashboard** developed to analyze and visualize Zepto's sales performance. The dashboard converts raw business data into meaningful insights, enabling better decision-making through dynamic visualizations and KPIs.

The dashboard is designed for business stakeholders to monitor sales trends, evaluate product performance, analyze customer behavior, and identify growth opportunities.

---

# 🎯 Objectives

- Analyze overall sales performance
- Monitor revenue and order trends
- Identify top-performing products and categories
- Evaluate customer purchasing behavior
- Compare regional sales performance
- Create interactive dashboards for business users

---

# 📊 Dashboard Features

- 📈 Sales Performance Overview
